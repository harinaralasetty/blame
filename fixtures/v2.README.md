Hand-written, not harness output.

`v2.jsonl` is generic JSONL that uses every optional record key (`agent`, `role`,
`error_kind`, `task_version`, `job_id`) and `score: null`. It follows no harness, so
there is no source commit to cite. Each task is built to give one of the eleven labels
as a verdict:

| Task | Verdicts |
| --- | --- |
| `errors` | `infra` (harness class and the 0.1.0 error rule), `setup_error`, `grader_error`, `unclassified_error`, and `genuine_failure` for an error the harness counts as a valid failure |
| `regraded` | `judge_unstable` |
| `reference-flaky` | `reference_flaky` |
| `reference-fails` | `reference_fails`, with `item_everyone_loses` as a second match |
| `all-zero` | `item_everyone_loses` |
| `unstated` | `unstated_requirement` |
| `flip` | `attempts_flip` |
| `plain` | `genuine_failure` |

The expected report is `tests/golden/v2.report.json` and `tests/golden/v2.report.md`.
